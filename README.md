# Sistema de Gerenciamento de Pratos

Sistema desenvolvido para um restaurante com o objetivo de centralizar o cadastro de usuários e o gerenciamento de pratos.

A aplicação permite cadastrar pratos, associá-los aos usuários responsáveis pelo cadastro e facilitar a organização dessas informações.

## Tecnologias utilizadas

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Funcionalidades

- Cadastro de usuários com nome e e-mail;
- Cadastro de pratos;
- Associação de cada prato ao usuário responsável pelo cadastro;
- Listagem de todos os pratos cadastrados;
- Visualização do usuário responsável por cada prato;
- Edição de pratos;
- Exclusão de pratos;
- Filtragem de pratos por usuário;
- Validação dos campos obrigatórios.
